05 / INÍCIO E REGRAS FIXAS

Como funciona o monitor

Em GitHub Actions, abra “Rotation Lab V4.1 - Paper Forward” e selecione “Run workflow”. Se a primeira execução falhar, consulte os logs.

2. Registrar

A primeira execução bem-sucedida cria só o marco inicial. Depois, a rotina tenta registrar uma observação a cada 4 horas.

3. Analisar

Volte aqui para consultar. No ChatGPT, diga “Analise V4”: consigo ler o mesmo JSON no seu repositório.

Ver regras congeladas da V4

Capital de R$ 50 virtuais; alocação de até 65% do caixa na compra; mínimo ilustrativo de R$ 30; meta de 2%; confirmação em 3 candles fechados; filtros de tendência BTC e moeda; stop estimado de 2,5% a 5%; espera de 12 candles após venda; freio permanente após queda acumulada de 6% do pico. Custos estimados de 0,1% de taxa mais 0,05% de slippage por lado.

O motor congela um hash da lógica e da configuração no marco inicial. Uma modificação posterior impede novas operações até que seja criada outra versão, evitando mudanças silenciosas de estratégia.

Os dados públicos não representam execução real. O saldo em R$ é apenas uma unidade contábil: não há conversão USDT/BRL, impostos, execução real, livro de ordens ou garantias de perda limitada. Se o GitHub Actions atrasar ou a API falhar, nenhuma ordem fictícia é preenchida retroativamente.
